まず一回だけ、これをやる

誰ツヨ理論の全部が乗っている前提を、30秒で自分の体に負けさせる稽古。相手も道具も要らない。ここを飛ばすと、以降の全部が「気合いで何とかなる」に化ける。

右足上げテストSOLO

  1. 両足で立ち、右足を上げる。上がる前に、体重が左へ移る。
  2. 「絶対に左へ寄らない」と決めてから、もう一度右足を上げる。それでも左へ移る。
  3. 10回連続で試し、左へ移らなかった回数を数える。
  4. スマホを腰の高さで横から撮り、腰が左へ動いてから右足が床を離れる順序を確認する。
合格10回中10回、右足が床を離れる前に腰が左へ動く。意志で決めても止まらないことが、映像で確認できる。

出典：かめはめ波が撃てる？ 怪しい技体験会 08:11 ／ 菊野の言葉は「これ取っちゃいますよね。これが反射です」

意志は反射に間に合わない。だから彼の技術は全部、相手の反射を呼ばないことに向いている。そして同時に、自分の側の反射（無意識の踏ん張り）を外すことに向いている。

前提。これを外すと全部インチキに見える

菊野の技を「格闘技として弱いのでは」と見た瞬間に、話が通じなくなる。彼が繰り返し言っているのは、格闘技と武術では正解が反転するということ。

KAKUTOGI — 競技

踏ん張るのが正解

ルールがあり、急所攻撃がなく、安全が担保されている。だから耐えれば生き残れるし、耐えながら殴り返せる。腹を括って歯を食いしばる状態が、そのまま強さになる。

BUJUTSU — 武術

踏ん張った瞬間に終わり

ルールがない。至近距離では頭突き・目・喉が先に届く。その距離で一瞬でも固まったら、そこで終わる。猫が車の前で固まるのと同じ反応が、ここでは致命傷になる。

猫がさ、車が来る時さ、ガッて固まるんだよね。多分猫は普通に生きてれば車よりとんでもないものはないから、固まった方が安全だと感じるんだと思うんだよね。ま、我々人間もそうなんだよね。脅威にさらされた時ってこっちの、固める方を選んでしまう。 なぜ弟子にしか技がかからないのか【天水モリカワ】 07:36

彼が売っているのは「体格や年齢を超える魔法」ではなく、格闘技側の最適解（踏ん張る）が、武術側では自殺になるという一点。ここは2020年から一度もブレていない。系統は沖縄拳法・大城健会の山城美智で、これも字幕で本人が明言している。

核の七条

701本を横断して、時代が変わっても言い方だけ変えて残り続けているものを抜いた。SOLO は一人で稽古も検定もできるもの、要相手 は触覚の相手がいないと成立しないもの。

一
遊びを取る SOLO

「遊び」＝関節と接点のガタ。機構でいうバックラッシュ。ガタがあると、自分が動いても力が自分の中で吸収され、相手に届くまでに時間差が出る。

ここが最初の関門で、脱力ではない。力むと相手の力を受け止めてしまい、緩むと遊びが出る。「撓まない・力まない・緩まない」。必要な張力は「糸電話が張る程度」と量まで指定されている。

取り方は4つに具体化されている

  • 伸ばす — 関節を伸ばし切るのではなく、関節と関節の"間"を伸ばす。伸び切ってロックすると、そこが縮んで力むので失格。
  • ひねる — 彼の定義では「ひねる＝螺旋状に伸ばすこと」。回旋ではなく伸張の一種。
  • 握る — 末端の握りで全身を引っ張る。ただし握り込みは力み＝遊びになる。
  • 呼吸で膨らむ／外旋 — 鼻から息が入って胴が膨らむ。脇を締めるは親指の外旋。
合格自分の腕を反対の手で触ってカチッとしていて、押しても動かない。彼の言い方は「触ると鉄」「土管」。
不合格きつさが関節に出ている。きつさは体幹・足裏・接点に出るのが正解で、関節やアウターに出たら間違い。
二
増えた分にだけ、耐えない SOLO

重力に対しては普通に立ったまま、あとから乗ってきた負荷にだけ耐えるのをやめる。無意識にかかっているブレーキを、意図的に外す稽古。

重力に対してはちゃんと立ってるんだけど、増えた分（負荷）に対しては耐えないでほしい。……この自分が無意識に頑張ってること、ちゃんとブレーキを今かけてるわけですね。それを意図的に外せるように。 【超有料級】…完全解説 04:44 ／ 画面テロップと音声

いちばん実用的なところ。「脱力しろ」ではなく重力への対抗はそのまま、増分にだけ譲る。菊野の体系で唯一許されている他動詞が「ブレーキを外す」で、それ以外の動きの指示はすべて自動詞になっている。

一人でやる

  1. 普通に立つ。姿勢は直さない。
  2. リュックに本を数冊入れて、ゆっくり背負う。
  3. 重さが増えた瞬間、増えた分だけ下に沈むに任せる。踏ん張って高さを保たない。
  4. ヘソが前に出たり膝が突っ張ったら、そこが「逃げた」場所。そこの踏ん張りだけ手放して、もう一度。
合格荷重が増えても、身体のどこにも新しい突っ張りが出ない。全身の高さがわずかに下がるだけ。
三
押さない、引かない 要相手

押すという行為そのものが、相手に「押された」という情報を渡し、防御反射を呼ぶ。だから押さない。強くすると相手も強くなる。

何もせずに、ただただ弱いところに踵をついて、その向きに仲良しのまま一緒に行くんですよ。……押さない引かないっていうのが大事ですね。 【超有料級】…完全解説 27:45 / 28:03

投げの一次原理は2023年から2026年まで一貫して「相手を変えない」。崩しとは重心を押し崩すことではなく、相手に検出可能な変化を渡さないこと。「差がなければ変化に気づけない」。

四
関係を変えず、別のところで1mmずつ 要相手

接触点の圧を、増やしも減らしもしない。増やせば反射が起き、減らせば遊びが出る。圧を一定に保ったまま、別の部位で動く。これが「見えない崩し」の実体。

それ以上増やすと反射が起きますし、減らしても力が抜けてきます。この、変えない。この関係性を変えずに、別のところで1mmずつ。 【超有料級】…完全解説 23:50

順序の指定もある。接触してから重心を移動させる。接触前に動かした重心は相手に伝わらない。

五
起こりを消す SOLO

予告情報を渡さない。予備動作だけでなく、呼吸・視線・意図も情報として漏れる。テロップはいつも「肉体的、精神的、起こりを消していく」。

消し方は動作の工夫ではなく意図の書き換え。「前に行こう」と思った瞬間に出るので、代わりに「自分が下に落ちる」「足を楽にする」に置き換える。相手はそれには準備反応しない。

視線の指定もある。相手は拳ではなく体のシルエットを見ているので、シルエットを止めたまま手だけを飛ばす。威力よりも「バレずに触る」が優先だと彼は言う（目・喉・金的を想定しているから）。

一人でやる

  1. スマホを横に置き、自分の突きを撮る。
  2. 打つ瞬間ではなく、その1秒前を1コマずつ見る。
  3. 肩・肘・手首・息・目線・重心のどれが先に動いているかを特定する。
  4. 先に動いた1つだけを消して、また撮る。
合格拳が出る前のコマに、動いている部位が1つも見つからない。肩・肘・手首が一度も上がらない。感覚ではなく映像で判定する。
六
重さを使う（地面を蹴らない） SOLO

地面を蹴れば速く遠くへ動けるが、身体は軽くなる。蹴らずに落ちると遅いが重い。彼はこれを禁止事項ではなくトレードオフとして提示している。

起点は「指先をほんのわずかに浮かすだけで重心が転がる」。踏み込みでも捻りでもなく、支えを微量に外して落ちる方向を作る。蹴りなら膝が先頭車両、体が後部車両。足は蹴る器官ではなく媒介物・パイプで、股関節は「あると思うと使ってしまうから、無いと思う」。

言い換えだけで支点が消える

いちばん今日から真似できる層がここ。「叩く」と思うと支点ができて力むので、「触る」「引っ張られる」「取りに行く」に言い換える。身体を変えるのではなく、動詞を変える。

七
選べること（これが本体） SOLO

力まないことが目的ではない。力める身体のまま、力まないでもいられる。その切替を自分で持つことが目的。

力んでる状態っていうのは居着いてる状態で、相手の攻撃を防ぐにはいいんですよ、吸収する。でも自分の動きも吸収しちゃうから威力が出づらい。……それをコントロールできる、選べる、選択できるってのが大事ですね。 【超有料級】…完全解説 06:33

ここが「四大原則」に接続する。人が相手と繋がる手段は姿勢・動き・リラックス・意識の四つ。この順に強度が高く、逆順に自由度が高い。姿勢は最強だが一方向にしか強くなく、意識は最弱だが全方向に使える。

「リラックス」の定義も独特で、柔らかさではなく均一。体に濃淡がなく、全身がその動作に協力している状態を指す。効くのは絶対値ではなく相対濃度で、肩も腰も足も頑張っていい。ただし末端（手のひら）より濃くなった瞬間に情報が漏れて、相手の反射が起きる。均一だから等速になり、加速は末端に頑張らせて作る。

そして彼の禁句が「こうでなければいけない、というのがもう力み」。「かからない」自慢も不自由の証拠とされる —— かかることも止めることも両方できるのが自由だから。

型は「通す」ものではない。3部品でしかない

公開されている素材に、ナイハンチ・セイサンの全挙動の順序は存在しない。あるのは立ち方・移動・第一挙動・突きの鍛錬だけ。だから「型を覚える」を予定に書くと、その日は何も検定できずに終わる。

部品 1 — 立ち方

ナイハンチ立ち

  1. 足幅＝骨盤2つ分。または脛の長さ（足の指先〜膝）＋拳1〜2個。
  2. つま先はまっすぐ前。足裏はベタッと。
  3. 足首は脱力する。ここを力むと体重が小指側へ逃げ、膝が内に入る。
  4. 膝と股関節は外へ全力で張る（ここは他動詞）。ただし曲げも伸ばしもしない。
  5. 背骨は上へ、腰は反らない。みぞおちを少し張って上下を繋ぐ。張りの量は糸電話程度。
合格鏡で正面から見て、膝を全力で外へ張ったままでも足指がまっすぐ前を向き、足裏の小指側が浮いていない。同時に足首だけは手で揺すれる（＝足首が脱力できている）。

なお重心の前後位置は、会員向け動画の字幕に「（秘密）」と明記されていて公開されていない。ここは推測で埋めない。

部品 2 — 移動

顔の重さで転がる横移動

  1. 骨の上に骨が乗って立ち、力を抜いても立っていられる状態になる。
  2. みぞおちがわずかに張り、糸電話程度の張りで上半身と下半身が繋がる。
  3. 顔が右を向き、その重さの分だけ右が重くなる。
  4. 地面を蹴らず、体も倒さず、その重さに沿って体が横へスライドする。
合格正面から撮って、頭のてっぺんが上下せず水平に平行移動している。移動の瞬間に頭が浮いたら地面を蹴った証拠で不合格。体が傾いたら重心が相殺されていて不合格。

部品 3 — 第一挙動

セイサン第一挙動

  1. 気をつけで楽に立ち、背骨と首が曲がらないまま股関節で礼をして戻る（背骨がリセットされる）。
  2. 左足が腰幅に開く。
  3. 鼻から息が入り、体が膨らんで遊びが取れる。
  4. 指を閉じて一本の剣にしたまま、手がみぞおちの高さまで上がる。肩で上げない ——「手が上がった結果、肩が上がる」。
  5. 指先から巻き取られて拳になり、拳が下＝遠くへ行く。
  6. 肘から先が伸びながら捻れる。雑巾が絞られる。
  7. 鼻から吸い、口から強烈に吐く。
合格終わりの形で前腕を反対の手で押しても動かない（鉄・土管の感触）。かつ楽にできたら不合格。上達するほどキツくなるのが正常。

「形を真似ても得られない」の中身

楽に形をなぞるのは鍛錬にならない。緩みは無意識が勝手にやるので、思っている3〜5倍張る。動作の切れ目ごとに張り直して、途切れさせない。合格の外形は本人の言い方で「1回通してへばる」。

回数の指定はほぼ無い。段階だけがある ── ①立ち方だけを1時間 ②型の全動作で遊びを取り続ける ③二人で肩の骨を触っての検証 ④三段階ミット。本気でやれば1ヶ月で打てるようになる、が本人の目安。

セイサンを一人でやるときの罠

「黙って綺麗にやると、軸足に乗ったままの偽物になる」。処方は声を出して不安定を作ること。静かに正確にやろうとするほど、検定が効かなくなる。

一人稽古の全メニュー

菊野が「一人でやる場合は」と明言している代替まで含めて並べた。全部、既存の生活か既存の筋トレに寄生させられる。彼自身は「僕四六時中稽古してますよ」「どんだけ自分の中で力まず歩けるか」と言っている。

土台 / 立つ

立禅（テンセグリティ立ち）

  1. 足が腰幅に開き、膝が伸びきりも曲がりもしない位置で楽に立つ。
  2. 重力に対して全身がぶら下がる（肩・肘は余計なことをしない）。
  3. そのぶら下がったまま、手が胸の高さで抱える形になる。
  4. 髪の毛・爪の先・腹・背中まで、全部がこの形をなすための張りに参加する。
合格どこか一箇所だけが先に音を上げない。足だけがきつい／肩だけがきついなら不合格。長く保つほど「みんなで分け合っている」状態に近づく。

※ これは站樁功と同じもの。別枠で二重に積まない。誰ツヨの土台の並びは「足の体操 → 椅子軸法 → 立禅 → スワイショウ」で、椅子軸法は西山創のイス軸法そのもの。手順は誰ツヨ側の素材には無い。

土台 / 立つ

一人綱引き

  1. ナイハンチ立ちまたはセイサン立ちで立つ。
  2. 前も後ろもぐわーっと伸び、体の中で綱引きが起きる。
  3. 力まないまま、遊びが取れていく。
  4. その状態のまま指先が浮き、重心が直る。
合格立っているだけで30秒〜1分で息が上がり、汗が出る。楽に立てていたら遊びが残っていて不合格。

負荷 / 既存の筋トレに寄生・0分追加

末端だけが動く筋トレ

種目を変えず、意図だけ差し替える。指定はこの3つ。

  • プッシュアップ＝拳が遠くへ行く。肩と肘は何もしない。降りる時も肘を曲げに行かず、拳だけが支えてゆっくり落ちる。
  • シットアップ＝頭が向こうへ行く。腹筋で上体を上げない。腹は重力落下したまま、縮めたくなるのをやらない。
  • スクワット＝足の裏が遠くへ行く。膝も股関節も曲げ伸ばししない。立つ時も膝を伸ばさず、足裏が遠くへ行った結果として立ち上がってくる。
合格動画で見て、関節の角度変化より先に接点の圧が動いている。降下速度が一定で「曲げに行く」加速がない。翌日のきつさが前腕・拳／腹の奥／足裏に出る。
不合格逐語で「関節がきつくなったら間違いね」。きつさが関節に出たらその場でやめて、意図を置き直す。

対人の代用 / 壁

壁押し（4方向）

  1. 壁に対して楽に立つ。寄りかからず自分で立つ。
  2. 肩と肘がぶら下がり、股関節は持ち上げず、ぶら下がったまま仕事をする。
  3. 手のひらが壁の向こうへ行く。腰は抜き、肩は上げない。
  4. 反力を「自分という一まとまりの重さ」で受け止め、手のひらだけがしんどい状態になる。
  5. 同じことを手の甲側・横向き・背中でもやる。
合格押している間、スタートの形（肩の高さ・前傾角）が変わらない。形が変わったら力が逃げた証拠。手のひらと足の裏だけがきつい。

対人の代用 / 壁

壁を触るだけで自分が動かされる

  1. 壁の前に立ち、触るぐらいのエネルギーで壁に触れる。
  2. 自分の中の力みをなくし、踏ん張らない（土台を作らない）。
  3. 反力を受け止めずに、体が真っすぐのラインのまま後ろへ動き出す。
  4. 自分から動かない。
合格触れるだけの圧で体が動き出す。動画で、頭〜足のラインが傾かず平行移動している。体が傾いたら足が踏ん張っている証拠。

これが二条（増えた分にだけ耐えない）の一人版。無意識のブレーキを外す稽古そのもの。

対人の代用 / 棒・自分の腕

押される接点を自作する

  1. 棒を壁に立てかけ、体の任意の接点（胸・背中・肩）に当てる。
  2. 接点をよく感じ、その接点が向こうへ行く。
  3. 接点の圧だけが増え、腰や関節は何もしない。
  4. 棒が無ければ、自分の腕同士を押し合わせて同じことをする。
合格接点と足の裏の圧だけが増えていて、腰・肩・股関節がきつくない。

呼吸 / 録音で判定できる唯一のドリル

音がしない鋭い呼吸

  1. 型や動作に呼吸を合わせる。
  2. 鼻から鋭く息が入る。シュッという音は立てない。
  3. フーッという大きくゆったりした呼吸にもしない。
  4. 刀で突き刺すような、その中間の集中状態になる。

(a) きつい＝上達（一人用）と (b) 手応えが無い＝成功（対人用）は逆を向いている。一人稽古で (a) をいくら積んでも (b) は測れない。菊野自身、視聴者の「正しくできてるかチェックするには」という質問に「これ仲間が必要ですね」「仲間も、ちょっとある程度分かる仲間が必要」と答えている。

さらに (a) には一般論としての注意がある。運動科学では上達＝運動の経済化（余計な筋活動が減る）が普通で、「きつくなるほど正しい」は逆向き。きつさの絶対量ではなく、きつさの出る場所で見るのが安全側。

強度の置き場所。ここだけは間違えると高くつく

理論の誤読より、この一点のほうがリスクが大きい。

手に強度を置かない

「1回通してへばる」「思っている3〜5倍張れ」という合格条件を、手・前腕の終端（引き手の絞り／拳の巻き取り／肘から先のひねり）で踏みにいくと、腱に効く。腱は筋より適応が遅く、手を使う仕事をしている人間にとっては単一障害点になる。

安全側の運用は単純で、強度は下半身・体幹の終端に寄せ、手は「触診でカチッ」までで止める。手側の合格判定は張力の量ではなく質（動かないか）だけにする。ナイハンチ立ち・一人綱引き・スクワット・壁押しはいくらきつくしてもいいが、引き手の絞りと拳の巻き取りは強度競争に使わない。

もう一つ。忖度で倒れるのも、意地で止めるのも、どちらも禁止とされている。対人の機会で「かからない」を誇るのは、選択肢が一つしかない不自由の証拠。かかることも止めることも両方できるのが自由、という立て付け。

固定順

  1. 情報を渡したか — 予告・合図・形の模倣・自分で膝を曲げた。全部が漏洩。
  2. 相手に余裕（遊び）があるか — 遊びがあれば吸収されて届かない。
  3. 相手が姿勢で耐えているか — 最強の層で受けられたら、姿勢でかける技は決まらない。
  4. 自分が「やりたい」を持ったか — 意図がそのまま起こりとして漏れる。

③に当たった回は技の失敗ではなく稽古設定の失敗として捨てる。①④に当たった回だけが自分の宿題として残る。原因欄を「相手が力んでいた」の一語で埋めるのも、全部自分のせいにするのも、どちらも切り分けの放棄。
